# BiliFocus v0.3.2 | 悬停查看计时与学习空间入口

面向 Chrome / Edge 电脑端的本地试用扩展，非哔哩哔哩官方产品。

## 本次调整

**计时默认隐藏。** 学习中，视频页右下角仅显示「悬停查看计时」提示。鼠标移到该区域才显示当前时间，移开立即隐藏。正计时和倒计时均适用；隐藏不影响计时、自动结束和记录。Tab 键聚焦该区域也能查看，移开焦点后隐藏。学习空间中的计时显示保持原样。

**视频页新增「打开学习空间」按钮。** 开始前和学习中均可使用，由浏览器打开或切换到扩展的学习空间。不替换当前视频页，不结束或重置当前学习。打开失败时会显示错误，可重试。

**一键开始和结束保持不变。** 结束时保存记录并解除限制，不需要跳转或输入确认文字。只有清空历史记录仍需要文字确认。本版没有新增扩展权限，未改动记录或白名单的存储键。

## 保留功能

- 视频页可选正计时或倒计时，点击即可开始。
- 学习中的右下角面板增加 UP 主下拉切换，直接在当前标签打开白名单账号的投稿页。
- 每次学习记录开始、结束、计时方式、结束原因、播放过的视频与 UP 主。分 P 单独记录。
- 学习空间新增“学习记录”分页，可按日查看模式时长、播放用时、场次和视频数。
- 跨午夜的记录自动分入两天，可导出当日 Markdown 小结和全部 JSON 记录。
- 学习期间仍然锁定两份白名单。视频页可一键结束；学习目录继续用于选课。

## 从 v0.3.1 / v0.3.0 更新

1. 先结束正在进行的学习，导出全部学习记录（JSON），并复制两份白名单作备份。
2. 解压新 ZIP，将新 BiliFocus 文件夹中的所有文件复制到原安装文件夹，覆盖同名文件。不要再嵌套一层 BiliFocus 文件夹。
3. 打开 `chrome://extensions` 或 `edge://extensions`，在原扩展卡片上点击重新加载。版本应为 **0.3.2**。
4. 刷新所有 B站页面和学习空间。不要同时启用新旧两个副本。

请使用同一安装文件夹、同一扩展和同一浏览器配置，不要先卸载。本版未更改白名单及记录的存储键，也不执行清空操作，可继续读取 v0.3.0 / v0.3.1 保存的记录。记录功能从 v0.3.0 开始，不会补出更早版本未记录的数据。

首次安装：开启扩展页的“开发者模式”，选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。不需要安装 Python 或 Node.js。

## 开始、换课与结束

先登录 B站，打开普通 BV 视频。右下角选择计时方式，点击“开始学习”。当前视频会加入白名单；勾选“同时放行当前 UP 主”会添加其发布账号。

你也可先在学习空间保存多位 UP：填入空间链接或数字 UID，一行一位。名单以 UID 识别账号，不以昵称猜测。白名单 UP 的全部普通投稿均可访问，包括可能存在的娱乐内容。

学习中，在面板下拉框选择 UP，点“切换”进入其投稿页。也可通过“换个学习视频”打开学习目录。这些操作不会结束或重置本次计时。

- **倒计时**：1—480 分钟，到时自动结束并存档。系统休眠后恢复时，按原定截止时间结算，不将超时部分多计入。
- **正计时**：从零持续累计，没有自动截止时间。关闭面板、浏览器或电脑休眠不会暂停模式计时。结束时请点击「结束学习」，避免忘记后计时持续增长。

手动结束：**视频页右下角 → 结束学习**。学习空间中也有同样的一键结束按钮。

## 记录口径：两种时长有区别

**学习模式时长**是从开始到结束的经过时间，包括选课、暂停、做笔记、离开网页和休眠。

**视频播放用时**根据播放器进度采样保守估计：仅对前台标签页或画中画、进度实际推进的播放累计。暂停、缓冲、拖动跳转、后台音频不直接算作播放时长。两倍速播放 10 分钟，记录约 10 分钟的用时，不是 20 分钟的课程内容长度。

多标签同时播放的重叠区间不会重复累加。仅打开页面不算“看过”，至少要有两次采样能确认进度推进。重看同一 BV 的同一分 P，时长会累加，视频数不重复增加。

这些数据不能证明注意力或知识掌握程度。大约每 5 秒采样一次，并在播放状态变化时尝试更新；跳页、强制关闭、休眠或播放器变化可能造成漏计，不保证逐秒精确。更改电脑时钟或时区也可能影响统计。

## 每天怎么查看

视频页面板「打开学习空间」 → **学习记录**，也可继续从浏览器右上角扩展进入。默认显示今天，可用日期选择器或箭头查看以前的日子。点击每场学习可展开视频明细。

日合计由已保存记录自动生成，不需要一直开着统计页，也不需要等到午夜才能看。此版本没有每晚推送通知功能。正在进行的会话会标注“进行中”。

## 数据、范围与限制

- 记录仅存在当前浏览器配置中，不上传、不调用 AI、不读取密码或 Cookie，不获取 B站原有观看历史。
- 仅学习模式中的白名单普通 BV 视频会采样；自由浏览不会记录。
- 最多保留 300 次学习，历史容量预算约 4 MB，超限会删除最早记录并显示清理数量。单次学习最多保存 500 个视频明细，超出后仅累计总播放时长并显示提示。
- 清空历史需要在非学习状态输入确认文字，不影响白名单。卸载前请先导出；此版支持导出但尚无导入界面。
- UP 放行仍使用 B站的视频信息接口识别主要发布账号，不是稳定性承诺的官方合作接口。失败时不自动放行。共同投稿仅按主要发布账号判断。
- 空间页仅放行白名单 UP 的普通投稿页，不放行动态、收藏、关注、直播等入口。不支持手机 APP、番剧、课程付费播放页或绕过会员限制。
- 这是专注辅助，无法阻止你关闭扩展、换浏览器或使用手机。

## 安装后先测试

开始正计时，播放约 20 秒。确认默认看不到计时数字；鼠标移到「悬停查看计时」区域时显示，移开后隐藏。点击「打开学习空间」，确认本次学习仍在继续。返回原视频页点击结束，检查本次记录与原有记录。再用 1 分钟倒计时确认隐藏时仍会到时自动结束。

如有异常，先在扩展管理页停用扩展并刷新 B站。排查只需错误信息或截图，不需要密码或 Cookie。
