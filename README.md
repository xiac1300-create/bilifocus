# BiliFocus · B站学习白名单

让 B 站在学习期间只保留你选择的视频和 UP 主，并在本机记录学习过程。

**当前版本：0.3.3 发布候选版。尚未通过插件商店审核，真实 B站页面兼容性仍需测试。**

本项目为独立的第三方浏览器扩展，与哔哩哔哩官方无隶属、合作或背书关系。

## 功能

- 在普通 BV 视频页一键开始、结束学习，支持正计时与倒计时。
- 计时数字默认隐藏，悬停或键盘聚焦时显示。
- BV 视频白名单、UP 主 UID 白名单；学习中可以跨白名单 UP 主切换。
- 学习期间限制 B站其他入口，并隐藏部分推荐、评论等干扰内容。
- 独立学习空间：查看场次、视频、分 P、每日汇总，导出 Markdown 或 JSON。
- 本地存储，无自建服务器、广告、统计 SDK 或 AI 调用。

UP 主白名单会放行该账号的全部普通投稿，包括其中的娱乐内容；扩展不会判断内容是否适合学习。

## 安装试用

适用于桌面版 Chromium 浏览器，Chrome 最低版本为 120。Edge 等浏览器的实际兼容性需验证。不支持手机 B站 APP。

1. [下载试用安装包](https://github.com/xiac1300-create/bilifocus/raw/refs/heads/main/downloads/BiliFocus-v0.3.3-store.zip)并解压；也可下载本仓库源码。安装包的 [SHA-256 校验值](downloads/BiliFocus-v0.3.3-store.zip.sha256)可用于核对下载完整性。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」。
4. 选择**直接含有 `manifest.json` 的目录**。不要选择 ZIP，也不要选择外层空目录。
5. 刷新已打开的 B站视频页。

普通用户无需安装 Node.js 或 Python。GitHub 下载和商店安装是两种分发方式；本仓库尚无商店安装链接。

## 开始使用

打开普通 BV 视频，在右下角面板选择计时方式并开始。当前视频会加入 BV 白名单；可选择同时放行当前 UP 主。

「打开学习空间」可以查看和管理白名单、学习记录。学习开始后名单锁定。「结束学习」会保存本场记录并恢复自由浏览。倒计时到时自动结束。

建议首次用 1 分钟倒计时，依次检查：开始 → 播放 → 切换白名单视频 → 尝试访问名单外内容 → 结束 → 查看记录。完整测试项见 [发布检查清单](docs/PUBLISHING.md)。

## 数据与时间口径

- **学习模式时长**：开始至结束经过的时间，包含暂停、做笔记、离开电脑与休眠。
- **视频播放用时**：根据前台或画中画播放器的进度采样，估算实际花费时间。倍速按现实时间计算；暂停、跳转、后台播放和长时间采样缺口不会直接累加。
- 正计时需要主动结束；关闭浏览器不会自动结束模式时长。
- 这些指标不能证明注意力或知识掌握程度。

仅在学习模式中对允许的普通视频进行记录，不读取 B站原有观看历史。记录仅在当前浏览器配置内保存，最多保留 300 场、历史容量预算约 4 MB，超限会清理最早记录并提示。支持导出，当前**没有导入界面**。

识别 UP 主时会向 `api.bilibili.com` 查询视频公开信息，发送 BV 编号并省略登录凭据；B站仍会收到 IP 等正常网络信息。详见 [隐私说明](PRIVACY.md)。

## 更新与备份

更新前结束学习、导出记录，并复制两份白名单。沿用原扩展和原安装目录覆盖文件，在扩展管理页重新加载，再刷新 B站页面。

不要先卸载。卸载、换浏览器配置或换扩展 ID 可能导致无法继续访问旧数据。将来迁移到商店版时，手动加载版与商店版可能使用不同 ID，不能承诺自动迁移；当前导出仅作备份，尚无直接导入功能。

## 边界与故障

这是自愿使用的专注辅助工具。停用扩展、换浏览器或使用手机均可绕过。它不提供家长控制、反卸载或强制监控能力。

UP 主识别依赖 B站当前接口和页面结构，接口限制、页面改版可能造成识别失败。失败时不会自动放行，可在学习前将视频单独加入 BV 白名单。不支持番剧、直播、付费课程页，也不绕过会员或付费限制。

异常时先停用扩展并刷新 B站。可通过 [Issues](https://github.com/xiac1300-create/bilifocus/issues) 提供浏览器版本、扩展版本、操作步骤和脱敏报错。**请勿上传 Cookie、密码、完整学习导出或个人浏览历史。**

## 开发与打包

使用 Node.js 20 或更新版本；运行和打包无需安装第三方依赖。

```text
npm test
npm run check
npm run pack
```

`pack` 通过明确文件清单生成 `dist/BiliFocus-v0.3.3-store.zip`，`manifest.json` 位于 ZIP 根目录，另写 SHA-256 校验文件。ZIP 不包含测试、开发文档、旧压缩包或个人数据。

现有 Python UI 测试属于离线模拟测试，可使用 Playwright 单独运行；它们不等同于真实扩展和 B站联调。当前验证范围见 [TESTING.md](TESTING.md)，历史设计说明见 [v0.3.2 使用说明](docs/README-v0.3.2.md)。
